# Support

Trouble getting VEGA running? Here's how to get help.

## Self-service first

Before opening an issue, please check:

1. **[GUIDA_UTENTE.md](GUIDA_UTENTE.md)** — full Italian user guide
2. **[CHEAT_SHEET.md](CHEAT_SHEET.md)** — 1-page reference card
3. **[ARCHITECTURE.md](ARCHITECTURE.md)** — how the 8 layers fit together
4. **[CHANGELOG.md](CHANGELOG.md)** — recent changes (your bug might already be fixed)
5. The **🛠 Operations Center** inside VEGA itself → tab **🏥 HEALTH** to see what's broken

## Channels (in order of preference)

### 1. GitHub Discussions
For questions, ideas, show-and-tell:
https://github.com/amirpiccardodev-maker/vega/discussions

### 2. GitHub Issues
For confirmed bugs and reproducible problems:
https://github.com/amirpiccardodev-maker/vega/issues

Please use the **bug report template** and include:
- VEGA version (from `CHANGELOG.md`)
- OS (Windows / Linux / macOS)
- Steps to reproduce
- Relevant logs from `data/audit.log.jsonl` (after masking sensitive data)

### 3. Security vulnerabilities
**Do not** open a public issue. See [SECURITY.md](SECURITY.md).

## Response time expectations

VEGA is a personal/community project. Reasonable expectations:

- **GitHub Discussions**: usually a few days
- **Bug reports**: triage within a week
- **Critical security**: 24-48 hours via the Security Advisory channel
- **Feature requests**: evaluated, but no SLA

## Commercial support

There is no paid support tier currently. If your organization is using VEGA in production, please open a Discussion to share your use case — we may add an enterprise FAQ.

## Community

Be patient, helpful, and constructive. See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
