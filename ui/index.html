📖 GUIDA RAPIDA

Parlare con Vega a voce

  • "Vega" / "Ehi Vega" / "Ok Vega" → attiva l'ascolto. Aspetta il bip.
  • Subito dopo, fai la domanda. Lui risponde a voce + testo.
  • "Stop Vega" → interrompe quando sta parlando.
  • Ascolto continuo (in Impostazioni): niente più "Vega" ogni volta, ti ascolta 60s dopo l'ultima risposta.
  • Interrupt vocale (opt-in, serve cuffie): parla mentre Vega parla → si ferma e ascolta.

Frasi tipo:

  • "Che ore sono", "che tempo fa", "leggimi le mail"
  • "Manda mail a Marco", "aggiungi todo: comprare pane"
  • "Genera immagine di un drago al tramonto"
  • "Guarda lo schermo e dimmi cosa vedi"
  • "Pensaci bene su X" → attiva ragionamento profondo
  • "Dibattito su: devo cambiare lavoro?" → 3 voci + sintesi

I tuoi 31 esperti virtuali

Apri 🏛 Automation Mode dalla topbar. Vedi 4 reparti:

  • Governance: Steward (direttore), Architect (consulente)
  • Compliance: DPO (privacy/GDPR), CISO (cybersec/NIS2), RSPP (sicurezza lavoro D.Lgs 81), Audit Watcher
  • Operations: Admin (fisco), Sales (CRM), Email Manager, Report Builder, Client Onboarding, HR, Training, File Org, Knowledge Mgmt, Bug Hunter, Innovator, Marketing, AI Expert
  • Intelligence: Scout daily da Garante Privacy, CSIRT, ANSA, Agenzia Entrate, INAIL

Tab 💬 Chat con agente: parla direttamente col DPO, CISO, Sales, ecc. in-character.

Comandi vocali speciali:

  • "Agente: organizza la mia settimana" → planner multi-step
  • "Missione: trova 5 case in affitto" → long-horizon (lavora autonomamente)

Cosa puoi chiedere

  • Info: meteo, news (📜 daily), wikipedia, ricerca web, vedo immagini, Excel/CSV
  • Mail: leggimi inbox, manda mail (sempre conferma prima)
  • Sistema: apri Spotify/Word, volume su/giù, blocca PC, screenshot
  • Memoria: "ricorda che X", "dimmi cosa sai su Marco" (clusterizza i ricordi)
  • Vision: trascina foto/PDF nella finestra, oppure "guarda lo schermo"
  • Image gen: "genera immagine di X" (gratis via Pollinations)
  • Timer: "imposta timer 10 minuti"
  • Compliance pro: "registra trattamento Art. 30 per cliente X", "scadenze fiscali questo mese"

Scorciatoie tastiera

  • F11: schermo intero
  • Invio: invia messaggio
  • Shift+Invio: nuova riga nel testo
  • Esc: chiudi modal/popup
  • Drag & drop: trascina file/immagini → Vega li analizza

Topbar (alto destra)

  • ?: questa guida
  • 🩺: diagnosi sistema
  • 🖥: stato PC dettagliato
  • 📊: statistiche uso + cache hit rate + costi
  • 🏛: Automation Mode (agenti)
  • 💡: proposte Innovator + suggerimenti
  • ⚙: impostazioni

La tua privacy

  • Tutto è locale: dati su tuo PC, niente cloud (a parte le chiamate AI ad Anthropic, già cifrate HTTPS).
  • Modalità privata (Impostazioni): conversazione non viene salvata in memoria.
  • PIN: protegge l'accesso da remoto (LAN/mobile). Da localhost niente PIN.
  • Mic kill switch: pillola in alto cliccabile → mic OFF immediato.
  • Honeypot: stringhe-trappola in memoria; se appaiono in output → alert leak.
  • Audit log: ogni azione tracciata con catena hash (tamper-evident).

Per cybersec dettagliata, apri 🏛 Automation Mode → chat col 🛡 CISO.
