CARTELLA DOCUMENTI PERSONALI
============================

Metti qui i tuoi file (PDF, .txt, .md, .docx) e poi di':

  "Hey Vega, indicizza i miei documenti"

Da quel momento Vega puo' cercare semanticamente al loro interno.

Esempi di domande dopo l'indicizzazione:

  "Cosa diceva il mio contratto sul preavviso?"
  "Trova la ricetta della carbonara nei miei appunti"
  "Cosa ho scritto sui clienti X nelle mie note?"
  "Quanto pago di affitto?"

Quando aggiungi/togli file:

  "Hey Vega, reindicizza i documenti"

Formati supportati:
  - PDF
  - .txt
  - .md / .markdown
  - .docx (Word)
  - .csv
  - .log

I file restano qui sul tuo PC. L'indice viene salvato in
docs_index.npz e docs_index_meta.json nella root del progetto.
